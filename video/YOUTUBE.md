## Description

```
Replication Radar makes the OpenAIRE Graph more useful for replication: search a field and see what's most worth replicating (impact-ranked) and whether each claim has already been independently checked — with the verdict — read live from the Science Live nanopublication network.

The principle: cite the claim, not the paper — and before you cite it, prove it. Citation follows proof.

Built for the OpenAIRE AI Hackathon (Theme B — Build). It's a live web app (no account, no keys) AND an MCP server that runs beside the OpenAIRE MCP, so an AI agent gets both the structural graph and the verification layer.

In this walkthrough:
• Search a field → impact-ranked targets + which claims are independently checked
• Open a signed Science Live nanopublication — the outcome and its evidence
• Reusable research software, scored live (FAIR + RSE practices: documented · tested · CI)
• Switch to an agent: the replication-radar MCP finds an un-replicated high-impact paper (Oliver et al. 2018, marine heatwaves), independent software (XMHW), and independent data (via the OpenAIRE MCP) — then scaffolds the replication

The payoff: that replication is now published as a signed, Validated constellation — with plain-language versions for citizens and for schools.
```
