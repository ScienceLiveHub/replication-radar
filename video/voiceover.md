**[Web app — you type a field and hit Scan]**
> Which high-impact papers are actually worth replicating — and has anyone checked them? The OpenAIRE Graph can't tell you. Replication Radar can.

**[Results + the replication-gap bar]**
> Search a field, and it ranks what's worth re-testing — then overlays, live from the Science Live nanopublication network, which claims were independently checked, and how they held up.

**[The VERIFIED card → the Science Live nanopub page]**
> This one *was* checked — validated, traceable to a signed nanopublication. That verification layer is exactly what a citation graph can't hold.

**[Cut to the Claude Code terminal — the bridge]**
> That's the human view. Now the same engine as an MCP — let's take one target all the way, with an AI agent.

**[`radar` tool call → Oliver 2018 appears]**
> The agent asks the Radar, over the OpenAIRE Graph, what's un-replicated. Top hit — a Nature paper: marine heatwaves, longer and more frequent. Highly cited, never independently checked.

**[`find_independent_software` → XMHW #1]**
> Which software could a research software engineer reuse? It ranks real tools by their reuse signal — GitHub stars, archival — and picks XMHW, an independent detector. It even catches one that *looks* independent but is the original author's own code.

**[`find_dataset` → "Called openaire" → ESA CCI dataset]**
> And the data? It hands off to the OpenAIRE MCP and finds an independent satellite dataset — a different producer from the original. So this is a true replication, not a re-run.

**[The scope-caveat text on screen]**
> And it's honest about scope: satellite data only reaches the nineteen-eighties, so this replicates the satellite era — the century-long trend stays an open question. A partial replication, stated plainly.

**[Repo created + DISCOVERY.md written]**
> Then it scaffolds the replication repo from the FORRT template — and writes down exactly what was decided: the paper, the data, the software. Nothing lost between discovering a target and doing the work.

**[Final terminal / end card]**
> Two MCPs on one Graph — discover what's worth checking, then go check it. Grounded, reproducible, signed. That's Replication Radar.

**[End card, optional tag]**
> openaire-hackathon dot netlify dot app. pip install replication-radar.
